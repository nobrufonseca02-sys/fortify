# Stripe Branding Checklist

Fortify Checkout, Customer Portal and invoices should use Stripe Dashboard branding.

1. Open Stripe Dashboard > Settings > Branding.
2. Upload the new Fortify icon for small surfaces.
3. Upload the Fortify wordmark/logo for Checkout and invoices.
4. Set the brand color to the Fortify cyan/dark visual style.
5. Apply the branding to Checkout, Payment Links, Customer Portal and invoices.
6. Run a test Checkout and confirm the new Fortify brand appears.

Do not hardcode local app asset paths into Stripe Checkout sessions.
